# GPRSaves.me
 
This is the starter repo for the GPRSaves.me website.
 
## Status
🚧 Under construction. A placeholder page is live while the real site is built.
 
## How it deploys
- Hosted on **Vercel**, connected to this GitHub repo
- Every change saved to the `main` branch automatically updates the live site
- Domain: **gprsaves.me**, connected in Vercel under Settings → Domains
- No build step needed for now; Vercel serves `index.html` as-is
